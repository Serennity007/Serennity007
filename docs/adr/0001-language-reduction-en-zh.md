# 0001 — 语言版本从 10 种精简为 EN + ZH

日期：2026-08-29
状态：已采纳

## 背景

README 曾同时维护 10 个语言版本（en / zh / ja / ko / fr / es / pt / ru / de / ar）。实际后果：

- 任何一次修改（换图片 URL、改用户名、改 npm 包名）都需要同步 10 个文件。2026-08 的三轮修复中每一轮都是 10 倍操作量。
- 非英语/中文来源的访问流量接近零。
- 10 个手工翻译版本必然逐渐失同步，产生内容漂移。

## 决策

只保留 `README.md`（英文，GitHub 默认展示）与 `README.zh.md`（中文）。其余 8 个语言文件删除（git 历史可随时找回）。

## 后果

- 修改成本降为原来的 1/5。
- 页面顶部语言切换行只保留 English | 中文。
- 若未来确实需要多语言（例如某个市场流量可验证地增长），用脚本从英文基准翻译生成，不做手工维护。
