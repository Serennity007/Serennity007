## 💬 使用场景

```bash
# PR 前 — 清理 commit 历史
git rebase -i main
npx git-format

# 开发中 — 让 AI 处理 commit message
git add .
npx ai-commit

# 接入新项目 — 检查仓库的 AI 准备度
git clone <repo> && cd <repo>
npx @liangzhengtao/vibe-check

# 调试 — 查看 AI Agent 实际做了什么
npx agent-trace --last-session
```
