## ⚡ Prueba uno en 10 segundos

Sin clonar. Sin clave API. Sin configuración. Ejecútalo directamente.

```bash
# Convierte el historial Git desordenado en Conventional Commits
npx git-format

# La IA genera tus mensajes de commit a partir de los cambios staged
npx ai-commit

# Evalúa la preparación AI de tu proyecto (0-100)
npx @liangzhengtao/vibe-check
```

Elige uno. Pégalo. Resultados inmediatos.

## 💬 Cómo la gente usa estas herramientas

```bash
# Antes de un PR — limpia el historial de commits
git rebase -i main
npx git-format

# Durante el desarrollo — deja que la IA maneje los mensajes de commit
git add .
npx ai-commit

# Onboarding — verifica si un repo está listo para codificación AI
git clone <repo> && cd <repo>
npx @liangzhengtao/vibe-check

# Depuración — ve lo que tu agente AI realmente hizo
npx agent-trace --last-session
```
