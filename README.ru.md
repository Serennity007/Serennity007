# Привет, я Zhengtao 👋

### Я создаю CLI-инструменты, автоматизирующие рутинные задачи в разработке ИИ.

Я пишу инструменты с открытым исходным кодом, которые управляют git-процессами, мониторингом агентов, аудитом проектов и генерацией коммитов — чтобы вы могли сосредоточиться на создании, а не на контроле.

## ⚡ Попробуйте за 10 секунд

Без клонирования. Без API-ключа. Без настройки. Просто запустите.

```bash
# Format messy git history into clean conventional commits
npx git-format

# Let AI write your commit messages from staged changes
npx ai-commit

# Score your project's AI-readiness (0-100)
npx @liangzhengtao/vibe-check
```

Выберите один. Вставьте. Результаты мгновенно.

## 💬 Как люди используют эти инструменты

```bash
# Before a PR — clean up your commit history
git rebase -i main
npx git-format

# During development — let AI handle commit messages
git add .
npx ai-commit

# Onboarding — check if a repo is ready for AI coding
git clone <repo> && cd <repo>
npx @liangzhengtao/vibe-check

# Debugging — see what your AI agent actually did
npx agent-trace --last-session
```
